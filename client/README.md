# Cloud Monitor — native client

Kotlin Multiplatform + Compose Multiplatform application (`composeApp`).

Full documentation (build commands, server URL rules, feature list, troubleshooting) is in the repository root [`README.md`](../README.md).

Quick start (Windows):

```powershell
cd client
.\build.ps1 :composeApp:compileKotlinDesktop
.\build.ps1 :composeApp:run
```

Linux / macOS: `./gradlew :composeApp:run` from this directory.
